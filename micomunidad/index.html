Falta conectar MiComunidad

Sigue estos 4 pasos (toma 5 minutos):

  1. 1
    Crea tu proyecto
    Entra a supabase.com y crea un proyecto gratis.
  2. 2
    Pega la base de datos
    SQL Editor → New query → pega el archivo supabase/schema.sql → Run.
  3. 3
    Activa el acceso anónimo
    Authentication → Sign In / Providers → activa Anonymous sign-ins.
  4. 4
    Pega tus llaves
    Supabase → Project Settings → API → copia el Project URL y la llave anon en micomunidad/config.js.

Cuando termines, vuelve a cargar esta página.
